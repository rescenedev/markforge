Why MarkForge

Native speed, real Markdown

⚡

GPU-accelerated

Rendered with Metal via GPUI — the same engine as the Zed editor. Sleeps at ~0% CPU when idle.

🗂️

File explorer

A VSCode-style sidebar (⌘B). Open a folder, browse the tree, click any file to open it — with native macOS selection.

🪶

Tiny & native

A single ~18 MB binary, ~70 MB RAM. No web view, no Electron, no runtime.

✍️

Split editor

⌘E into a resizable source editor with syntax highlighting and live preview as you type.

♻️

Live reload

Edit a file in any other app and MarkForge updates instantly — debounced for smooth typing.

🌗

Light · Dark · System

Follows your macOS appearance, or pick a fixed theme. Zoom and fonts are configurable and persisted.

📂

Open anywhere

File dialog, drag-and-drop, recent files, or a command-line argument. Your settings travel with you.

Install

Up and running in seconds

# Homebrew (recommended)
brew install --cask rescenedev/tap/markforge
# or build from source (needs Rust)
git clone https://github.com/rescenedev/markforge && cd markforge && cargo run --release
